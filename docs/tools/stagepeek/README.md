# StagePeek

## 简介

[StagePeek](https://stagepeek.live/) 是一款覆盖全球 201 座演唱会体育场、室内体育馆与剧院的 2D 座位图与 3D 舞台视野模拟器。购票前输入区号、排号与座位号，即可在浏览器中查看 1.18 米人眼坐姿视角下的舞台朝向、仰角、三种舞台布台（End Stage / Thrust Runway / 360° Center）以及 1x–10x 手机变焦模拟效果。

## 功能特点

- 201 座全球场馆 100% 定制 3D 建筑壳体模型（含 32 座旗舰场馆精确坐标选座与 536+ 场 2026–2027 巡演日程）
- 支持 1x–10x 手机镜头构图模拟与直线估算距离显示
- 内置英语、简体中文（[stagepeek.live/zh-CN/](https://stagepeek.live/zh-CN/)）、繁体中文、日语、韩语 5 种语言，并提供 `/explore?embed=1` iframe 嵌入组件
- 免登录即可免费浏览全部 201 座场馆地图并预览首个座位视野（登录免费账户每馆可预览 4 个座位；Pro 畅享版 $4.99/周起）
