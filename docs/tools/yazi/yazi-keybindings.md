# Yazi 快捷键完整参考

> 基准版本：yazi v26.8.15（2026-08-15）| 键位数据基于官方 `keymap-default.toml` 源码逐条核对
> 随时按 `~`（或 `F1`）打开程序内帮助菜单——它显示的就是你当前配置的实际生效键位，定制过的键也会如实列出。

## 键位分层总览

Yazi 的快捷键按**上下文（context）分层**，共 9 层，每层独立键位表：

| 上下文层 | 键位数 | 说明 |
|---|---|---|
| `[mgr]` | 116 | 文件管理主界面（日常操作 95% 在此层） |
| `[tasks]` | 12 | 任务管理面板（`w` 唤出） |
| `[spot]` | 15 | 文件信息弹层（`Tab` 唤出） |
| `[pick]` | 10 | 选项列表弹窗（如 `O` 交互式打开） |
| `[input]` | 68 | 输入框（重命名/新建/查找，Vim 风格编辑） |
| `[confirm]` | 12 | 确认对话框（删除确认等） |
| `[cmp]` | 11 | 自动补全（`cd` 路径补全等） |
| `[help]` | 10 | 帮助菜单 |
| **合计** | **254** | — |

## 主界面（mgr 层）9 大分组

### 1. 导航移动

| 按键 | 动作 | 说明 |
|---|---|---|
| `j` / `↑` | 下移光标 | Vim 风格 |
| `k` / `↓` | 上移光标 | |
| `h` / `←` | 返回上级目录 | |
| `l` / `→` | 进入目录 | ⚠️ 仅目录生效，文件上无反应（见 [README 常见问题](README.md#q1按-l-打不开文件)） |
| `H` / `L` | 目录历史后退 / 前进 | |
| `gg` / `G` | 跳到列表顶部 / 底部 | |
| `<C-u>` / `<C-d>` | 上 / 下翻半页 | |
| `<C-b>` / `<C-f>` | 上 / 下翻一页 | 即 PageUp / PageDown |
| `K` / `J` | 预览面板上 / 下滚动 | 滚的是右侧预览内容，列表光标不动 |
| `z` | **fzf 模糊跳转** | 按名字从全盘候选模糊匹配文件/目录（需 fzf ≥ 0.53） |
| `Z` | **zoxide 跳转** | 按访问频率跳到历史目录（与 shell 共享数据库） |
| `g⇒h` | 回到主目录 `~` | |
| `g⇒c` | 跳到 `~/.config` | |
| `g⇒d` | 跳到 `~/Downloads` | |
| `g⇒t` | 进入回收站 | |
| `g⇒Space` | 交互式跳转 | 带补全的路径输入 |
| `g⇒f` | 跟随符号链接 | |

> `⇒` 表示按键序列（先按 `g` 再按第二个键）。

**实战**：忘了文件在哪 → `z` 输入名字片段全盘模糊跳；日常目录往返 → `Z`（按频次排序）。看长文档 → 光标停在文件上按 `J`/`K` 滚预览，列表不动。

| `<C-a>` | 全选 | |

### 4. 打开与外部调用

| 按键 | 动作 | 说明 |
|---|---|---|
| `o` / `Enter` | 按打开器规则打开 | 走 `yazi.toml` 的 `[open]` 规则链 |
| `O` | 交互式打开 | 弹出 opener 列表人工选 |

**语义辨析**（新手最大坑）：`l` = **进入**目录；`o`/`Enter` = **打开**（目录则进入、文件交 opener 规则）。可用 smart-enter 插件消除心智负担，见[配置指南](yazi-configuration.md#案例-2smart-enter--prepend_keymap)。

**实战**：`.md` 默认进 VS Code，临时想用系统预览看一眼 → `O` 从列表选，不用改配置。

| 按键 | 动作 | 依赖 | 说明 |

| `<C-s>` | 取消进行中的搜索 | — | |

**四者辨析**：`/` 当前列表定位；`f` 当前列表筛选视图；`s`/`S` 跨目录递归搜索；`z` 全盘模糊跳转。

**实战**：当前目录筛出所有 `.ts` → `f` 输入 `ts` → 批量选中复制 → `Esc` 清过滤。跨目录找 → `s`。

## 弹层上下文键位概要

### `[spot]` 文件信息面板
`Tab`/`Esc` 关闭；`j`/`k` 滚动；`h`/`l` 切到上一个/下一个文件（连续查看多个文件属性）；`cc` 复制单元格内容。

### `[input]` 输入框（68 条，键位最多的一层）
完整 Vim 风格行编辑器——重命名、查找、新建时实际都在用它：

| 类别 | 按键 |
|---|---|
| 模式 | `i` 插入 / `a` 追加 / `v` 可视选择 / `I` `A` 行首尾 / `r` 替换单字符 |
| 移动 | `h`/`l` 字符、`b`/`w`/`e` 词、`0`/`$`/`^` 行首尾、`<C-a>`/`<C-e>` |
| 删除 | `Backspace` 前删、`x` 删单字符、`D`/`C` 剪到行尾、`<C-u>`/`<C-k>` 删到行首/尾、`<C-w>` 删前词 |
| 剪贴板 | `y` 复制、`p`/`P` 粘贴 |
| 撤销 | `u` 撤销、`<C-r>` 重做 |
| 历史 | `↑`/`↓` 或 `<C-p>`/`<C-n>` 翻输入历史 |

### `[confirm]` / `[pick]` / `[cmp]`
- 确认框：`y`/`Enter` 确认，`n`/`Esc` 取消
- 选项列表：`Enter` 提交，`j`/`k` 移动
- 补全：`Tab` 接受补全，`Enter` 补全并提交，`<C-p>`/`<C-n>` 选项移动

## 自定义键位：keymap.toml

### 覆盖机制（三选一）

| 属性 | 优先级 | 语义 |
|---|---|---|
| `prepend_keymap` | **高于**默认 | 插队默认键位**之前**，可**覆盖**默认键 |
| `append_keymap` | 低于默认 | 垫底默认之后，只能**新增**键 |
| `keymap = [...]` | 替换 | 覆盖该层**全部**默认键位（慎用） |

原理：yazi 取**第一个匹配**的键位执行，所以 prepend 总能赢过默认。要"禁用"某默认键用 `run = "noop"`。

> ⚠️ 同一层内 `prepend_keymap = [...]` 与 `[[mgr.append_keymap]]` 两种 TOML 写法**不能混用**，要么全用内联表风格、要么全用表数组风格。

配置保存后**自动热加载**，无需重启。

### 键位表示法速查

```toml
# ~/.config/yazi/keymap.toml
[mgr]
prepend_keymap = [
  { on = "l",          run = "plugin smart-enter",      desc = "进入目录或打开文件" },
  { on = ["g", "d"],   run = "cd ~/dev",                desc = "跳到开发目录" },   # 序列键
  { on = "<C-S-b>",    run = ["arrow top", "toggle"],   desc = "多动作" },         # 动作数组依次执行
  { on = "x",          run = "shell -- trash-put %s",   desc = "回收站", for = "macos" },  # 平台限定
  { on = "T",          run = "noop" },                  # 禁用默认键
]
```

- 修饰键：`<S-…>` Shift、`<C-…>` Ctrl、`<A-…>` Alt（macOS 需终端把 Option 映射为 Alt）、`<D-…>` Cmd（需终端支持 CSI u）
- `shell` 命令用 `--` 分隔符写法：`shell -- cmd %s`（旧写法 `shell "cmd %s"` 已废弃）
- 条件占位符：`%s` 全部选中、`%h` 悬停项、`%d` 目录名（大写为 URL 形式）

完整官方文档：[Configuration: Keymap](https://yazi-rs.github.io/docs/configuration/keymap)
