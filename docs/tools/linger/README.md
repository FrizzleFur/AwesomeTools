# Linger

## 简介

Linger 是一款付费、闭源的本地 macOS 视觉参考与图片管理应用。

## 功能特点

- 保存图片来源链接、个人笔记和色板。
- 按标签或颜色查找参考图片，在画布上整理。

## 安装指南

需要 macOS 14 或更高版本和 Apple Silicon Mac。从 [官网下载 DMG](https://withlinger.com/releases/Linger-0.8.9-15-arm64.dmg)。

## 快速开始

将视觉参考保存到图库，添加来源和笔记，使用标签或颜色查找，并在画布上整理。
