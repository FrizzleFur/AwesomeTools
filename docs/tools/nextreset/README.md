# NextReset

## 简介

[NextReset](https://nextreset.ai/) 是一个免费的独立参考站，整理带来源链接的 Codex 公共重置历史和官方 AI 服务事故信息，并提供保存在浏览器本地的个人倒计时。

## 功能特点

- 把公开重置信号与原始来源关联起来。
- 汇总官方服务状态与事故来源，帮助排查服务异常。
- 个人倒计时只保存在浏览器中，不读取私人账号用量。
- 实验性预测不保证具体重置时间。

## 快速开始

1. 打开 [NextReset](https://nextreset.ai/)。
2. 查看公开的 Codex 重置历史和相关来源。
3. 如需个人提醒，在浏览器中设置本地倒计时。
4. 如果问题可能来自服务故障，核对页面链接的官方状态来源。

## 适用场景

- Codex 会话停止后，区分可能的用量重置与官方服务事故。
- 回看公开、可核验的重置信号。
- 在不上传私人账号数据的情况下保存个人倒计时。

## 限制

NextReset 与 OpenAI 或 Anthropic 没有隶属关系，也不能读取私人账户的真实额度或保证重置发生时间。
